# Japan in Numbers

A static national statistics site for Japan: population, economy,
society and regional figures presented the way a statistics office
would publish them - big headline numbers first, then the series,
tables and notes behind them.

The site is fully self-contained. It makes no network requests, loads
no external fonts, scripts or images, and works offline straight from
the file system or any static host.

## Sections

- **Overview** - four headline indicators (population, GDP, median
  age, life expectancy), a population chart for 1960-2024, a
  "Japan at a glance" fact grid, and cards into every section.
- **Population** - the 1960-2024 population curve with a working
  year-range slider, age structure bars for 1990 against 2024, and
  key figures for median age, fertility and life expectancy.
- **Economy** - GDP trend 2000-2023 in current US dollars, GDP per
  capita, unemployment and labour force figures, and an exports
  against imports chart for 2023.
- **Society** - life expectancy by sex, household size and
  one-person households, education enrollment and health indicators.
- **Regions** - the ten largest prefectures by 2020 census
  population in a sortable table, plus a note on Greater Tokyo.

## Run it

Validate the entry and write the dossier:

```sh
node main.ts
```

This checks that `app/` is complete, reads the metadata and series
out of `app/data.js`, and writes `out/dossier.json` describing the
site, its sections, its counted indicators and a byte-size inventory
of every file in the entry.

Preview the site either by opening `app/index.html` in a browser, or
with the bundled preview server:

```sh
node serve.ts        # then visit http://localhost:4173/
```

## Data sources

Figures are published values from the Statistics Bureau of Japan,
the e-Stat portal, and the World Bank, reproduced as published:
the population series 1960-2024 with its 2008/2010 peak of 128.1
million, the 2020 census total of 126.15 million, GDP and GDP per
capita for 2023, the 2020 census prefecture populations, and the
vital and labour statistics quoted in each section. The site is a
summary for orientation, not an official publication.

## File structure

```text
main.ts            entrypoint: validates app/, writes out/dossier.json
serve.ts           small static server for local preview of app/
shots.json         screenshot definitions (name, size, route)
app/
  index.html       page shell: masthead, section nav, footer
  style.css        the site's stylesheet (navy, white, hinomaru red)
  data.js          every figure and series the site renders
  views.js         per-section renderers and canvas chart helpers
  main.js          hash router and nav state
vendor/
  makefun-frontend.ts   make.fun frontend helper (from the bounty kit)
screenshots/       rendered captures listed in shots.json
out/dossier.json   generated by node main.ts
LICENSE            MIT license
```

## Screenshots

`shots.json` defines four captures: the overview, population and

viewport. The rendered files live in `screenshots/`.
